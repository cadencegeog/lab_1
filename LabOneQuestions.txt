1. These statements are not equivelent. The geometries of both datasets are different- d.stations being point data, while del.counties is polygon. In that sense,
if we were to put "d.stations" first, our station data would be overlayed over polygons. If we were to use "del.counties" first, we would make the primary layout
the polygon data, and the station point data would be displayed after the polygons, which would be a problem if we were to do a spatial projection of the intersection.
If we were wanting to focus on counties and use certain data from d.stations, such as "Drainage_A", using the sf::st_intersection(del.counties, d.stations) might be
helpful.
